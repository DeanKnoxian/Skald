# Skald changelog

## 1.0.0 — planned initial release

The final installer is being prepared. This entry describes the intended first release; it is not a download announcement.

- Nordic and Atmoran themed landscapes, homes, equipment and character options.
- Expanded combat, movement, perks and magic, with the supplied compatibility setup.
- NORDIC UI, QuickLoot and Wheeler equipment wheels.
- Keyboard and mouse support plus a custom Xbox controller preset.
- Optional Frosthavn character progression through Runa's guidance and Tsun's trials.
- An organized Skald profile with named mod sections and a ready-to-use launch entry.

The current Main File status and release date will be listed on [Skald's Nexus page](https://www.nexusmods.com/skyrimspecialedition/mods/193977).
